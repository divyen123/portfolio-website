# R M Divyen Portfolio Website

This repository contains the source code for my personal portfolio website. The site is designed to give visitors a clear view of who I am, what I build, and the technologies I work with. It highlights my frontend development skills, UI/UX design practice, full-stack project experience, and continuous learning through certifications.

## About Me

I am passionate about building modern, responsive, and user-friendly web applications. My focus is on creating clean interfaces, writing maintainable code, and turning ideas into polished digital experiences that are easy to use across devices.

I have experience with React.js, JavaScript, HTML, CSS, Python, Java, UI/UX design, and full-stack application workflows. I am currently pursuing Information Technology at R.M.K Engineering College and continue to strengthen my skills through real projects and certifications.

## Key Features

- Responsive portfolio layout for desktop, tablet, and mobile screens
- Animated section transitions using Framer Motion
- Project showcase with images, descriptions, highlights, and live links
- Skills, education, and certificates sections
- Contact form integrated with FormSubmit
- SEO-ready metadata and polished visual presentation
- Built with reusable React components and centralized portfolio data
